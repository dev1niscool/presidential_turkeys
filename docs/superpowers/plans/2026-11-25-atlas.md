# Presidential Turkeys Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for implementation and independent final review.

**Goal:** Publish a researched, tasteful presidential turkey atlas on GitHub Pages.
**Architecture:** Static HTML/CSS with ES modules and JSON records. Browser-side filtering and native dialog profiles; all assets relative and photos local.
**Tech Stack:** HTML, CSS, JavaScript, Node built-in test runner.
**Spec:** docs/superpowers/specs/2026-11-25-atlas-design.md

## Global constraints
- User delegated decisions and authorized GitHub and Pages publication.
- Annual coverage from 1989 through latest verified ceremony; explicit uncertainties.
- Accurate photo identity, local assets, source and license credits.
- No runtime framework, backend, or credentials in source.

## Review focus
- Mixed-case searches, whitespace, and intersecting filters.
- No results and reset restoring all records.
- Direct profile links, keyboard escape, and back navigation.
- Narrow screens, image loading failures, readable labels.
- Unknown early names, absent photographs, and no unverified current-year claim.
